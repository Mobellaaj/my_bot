# ROS 2 Autonomous Mobile Robot 🤖

A personal robotics project focused on developing and simulating a differential-drive mobile robot capable of autonomous navigation using **ROS 2, Gazebo, SLAM, and Nav2**.

The goal is to gain practical experience with robot modeling, simulation, sensor integration, localization, mapping, and autonomous navigation.

## Project Objectives

- Build and simulate a differential-drive mobile robot in Gazebo.
- Implement manual robot control using ROS 2.
- Integrate simulated LiDAR and camera sensors.
- Perform real-time mapping and localization using SLAM.
- Implement autonomous path planning and obstacle avoidance using Nav2.
- Visualize robot behavior, sensor data, and navigation in RViz.

## Tech Stack

| Technology | Purpose |
|---|---|
| ROS 2 Jazzy | Robotics middleware |
| Gazebo Harmonic | Robot simulation |
| RViz2 | Visualization |
| Python / C++ | Robot programming |
| SLAM Toolbox | Mapping and localization |
| Nav2 | Autonomous navigation |
| URDF / Xacro | Robot modeling |
